# Flappy Hand 🖐

MediaPipe el tespiti ve OpenCV ile geliştirilmiş, **el hareketleriyle** oynanan Flappy Bird oyunu.

## Kontroller
- ✊ **Yumruk** → Oyunu başlat / yeniden başlat
- 🖐 **Açık El** → Duraklat / menüyü aç
- ☝️ **İşaret Parmağı** → Menü butonu seç

## Kurulum
pip install opencv-python mediapipe

## Çalıştırma
python main.py

## Kaynaklar
- [MediaPipe Hand Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker)
- [OpenCV Python](https://docs.opencv.org/)
- Oyun mekaniği ve menü sistemi — özgün implementasyon
